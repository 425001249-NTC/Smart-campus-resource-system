Smart Campus Student Resource Management System

Repository Structure
This repository follows the exact structural guidelines required for our terminal assessment evaluation:

* src/: Contains `main.cpp` (the complete C++ system source code).
* documentation/: Holds `test-cases.pdf` (10 formal execution test cases) and `complexity-analysis.pdf` (Big-O analysis).
* screenshots/: Visual proof of the working terminal application.

Core Functional Features
Our console-based application manages student records and analyzes campus resource usage inside a single BSIT section using linear data structures:

1. Student Records Directory: Add, display, search, update, and delete active student records.
2. Resource Tracking Matrix: A 2D array analysis grid tracking department resource hours.
3. Core Concepts Applied: Abstract Data Types (ADTs), C++ Pointers, Dynamic Memory (`new`/`delete`), and Data validation.
